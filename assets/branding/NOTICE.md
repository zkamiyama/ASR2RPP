# Executable icons

The white glyphs are Google Material Icons, Apache License 2.0, from the official
`google/material-design-icons` 4.0.0 set: `equalizer`, `code`, `mic`,
`record_voice_over`, `tune`, and `refresh`. The full license is in
`../icons/LICENSE.txt`. The glyph geometry is retained; ASR2RPP adds a dark teal
rounded background, changes the foreground color, and renders multi-size ICOs.
No Google logo, icon font, system font, or endorsement is included.

Sources: https://github.com/google/material-design-icons/tree/4.0.0/src
The tune/refresh glyphs also remain in the application's existing Material SVG set.

Application / command line / speech recognition / speech detection / audio engine /
model conversion use distinct glyphs, with a shared high-contrast background.
Each ICO contains 16, 20, 24, 32, 40, 48, 64, 128 and 256-pixel images.
Only this application's distribution is branded. Downloaded FFmpeg and files
elsewhere on the user's computer are not changed.
