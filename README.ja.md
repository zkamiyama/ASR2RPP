# ASR2RPP

**音声や動画を文字起こしして、編集できるREAPERプロジェクトを作ります。**

発話の位置にテキスト付きのアイテムを配置した `.rpp` ファイルを作成します。
必要に応じて背景音の除去、発話時刻の調整、話者ごとのトラック分けもできます。
元の音声・動画ファイルは書き換えません。

## Windowsで使い始める

1. [リリースページ](https://github.com/zkamiyama/ASR2RPP/releases)から、最新の **ASR2RPP-Windows-x64.zip** を取得します。
2. ZIPを**新しいフォルダーへ、すべて展開**します。ZIP内から直接起動したり、EXEだけを移動したりしないでください。
3. **ASR2RPP.exe** を起動し、音声・動画をキューへドラッグします。
4. 音声認識モデルを選び、**GO** を押します。最初の動作確認では **Whisper Base** を選び、任意の工程はOFFのままで試してください。
5. 作成された **`.rpp` をREAPERで開きます**。初期設定では入力ファイルと同じ場所に保存します。完了した行をダブルクリックすると出力フォルダーが開きます。

Windows版はAVX2対応のx64 PC向けです。プロジェクトを開くためのREAPERは別途必要です。
PythonやPyTorchを自分で入れる必要はありません。
現在のビルドは未署名のため、Windowsが警告を表示する場合があります。
このリポジトリのZIPを使い、配布されたSHA-256で照合してください。

初回はモデル取得のためにインターネット接続が必要です。大きなモデルでは取得に時間がかかり、
数GBの空き容量が必要になります。メディアの読み込みにはFFmpegを使います。
見つからない場合は、検証付きで自動取得します。取得済みのモデルやFFmpegは再利用します。
モデルごとにライセンスや利用条件が異なる点に注意してください。

## 工程を選ぶ

| 工程 | すること |
|---|---|
| 音声認識 | 話している内容をテキストにします。常に有効です。 |
| 背景音除去 | 音楽などの背景音から発話を取り出します。必要なときだけONにします。 |
| 強制アライメント | 認識テキストと音声を照合し、時刻を細かく合わせます。モデルが必須と指定した場合以外は任意です。 |
| 話者ダイアライゼーション | 発話に話者を割り当て、話者別のトラックにします。重なった声を別々の音声に分離する機能ではありません。 |

**Anime Whisper** では、発話区間を検出して短い区間ごとに認識します。
アライメントOFF時のアイテムは、単語の正確な境界ではなく**発話区間全体の時刻**を使います。
細かく時刻を合わせたい場合はアライメントをONにしてください。
文字起こしや話者の判定には誤りがあるため、編集・公開前に確認してください。

Vulkanが使えない、またはエラーになる場合は **CPU** を選んでください。
右下の設定ボタンから、出力先、モデル保存先、実行環境などを変更できます。
初回の表示言語は日本語環境なら日本語、それ以外は英語です。
言語ボタン、または **Ctrl+Shift+L** で切り替えられ、選択は保存されます。

## 止めて、もう一度実行する

**STOP** を押し、停止処理が終わるまで待ちます。再び **GO** が押せるようになったら、
中断・失敗した項目と待機中の項目を再実行できます。**完了済みの項目は再実行しません。**
完了したファイルをもう一度処理する場合は、その行をキューから削除して追加し直してください。

失敗理由はウィンドウ下部のログに表示され、選択してコピーできます。
原因を確認して設定や入力を直したあと、GOで再試行してください。

## 出力ファイルについて

最上段の **ORIGINAL** トラックは、無音も含む参照音源全体を1つのアイテムで保持します。
編集トラックとの二重再生を避けるため、最初は**ミュート**です。
比較するときはORIGINALのミュートを解除し、ほかのトラックをミュートするか、ORIGINALをソロにします。

その下に **Transcript**、または話者別のトラックが並びます。
発話ごとの音声ファイルを作るのではなく、元メディアを参照します。
参照先を移動・削除すると音が見つからなくなるので、プロジェクトと一緒に保管してください。

背景音除去をONにして **RPP音声 → 処理済み** を選ぶと、プロジェクトの隣に
連続した `*_vocals.wav` を保存し、その音声を参照します。
同名の出力がある場合は番号を付け、既存ファイルを上書きしません。
隣の `.asr2rpp` フォルダーには診断情報や認識テキストが入ります。
私的な内容を含むことがあるため、確認せず公開しないでください。

## 更新とモデル定義

更新版は**新しいフォルダー**へ全展開してください。
設定や取得済みモデルは通常 `%LOCALAPPDATA%\ASR2RPP` にあり、そのまま再利用できます。

モデル定義は **EXEの隣にある `models` フォルダーを直接読みます**。
同梱TOMLを一時フォルダーへコピーしません。通常は編集不要です。
独自モデルを追加する場合は **設定 → 詳細 → 独自TOMLを開く** を使い、
同梱モデルと異なる名前のTOMLを置いてください。
GOの前に再読込し、不正な定義や名前の競合は通知します。別モデルへ黙って切り替えません。

詳しいモデル設定は[モデルガイド](docs/inference-policy.md)に、
[開発手順や経緯](docs/development.md)は別の文書にまとめています。

## 0.2: timing and model runtimes / 時刻設定とモデル追加

設定 → 時刻で、自動・モデル時刻・VAD発話区間・強制アライメントを選択できます。
Qwen3-ASR、ReazonSpeech K2、faster-whisperの定義を追加しました。
時刻の付与方法を変えるためにTOMLを編集する必要はありません。
追加方法と実行環境の更新は [Provider/model guide](docs/provider-models.md) を参照してください。
