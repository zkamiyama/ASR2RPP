## Windows: exact frozen ZIP on the authorized RTX 4080 computer

All **20 shipped model definitions passed** acquisition, nonempty recognition, bounded timing, unchanged input and **RPP/OTIO/JSON** export checks. Nineteen native model/stage cases used Vulkan; ReazonSpeech used CPU. This covers 7 whisper.cpp definitions, 9 audio.cpp ASR definitions, 3 auxiliary stages and the ReazonSpeech worker.

The actual frozen GUI (not an inference stub) was launched with isolated settings. Its default was **Anime Whisper / ja / RPP only**. Adding OTIO/JSON through its menus and pressing GO completed real Vulkan recognition and three-format export. The CLI also passed with no model, language or format override. Ten deterministic frozen GUI lifecycle cases separately covered stop/retry, error recovery, empty-format rejection and preference persistence. Standalone JSON replay and CLI empty-format rejection passed.

Windows CI: **380 Python/Qt tests passed**, native PCM tests, frozen package/export/optional-stage checks passed. The authorized computer's source run had **379 passed, 1 permission-dependent symlink skip**. The final matrix and additional acceptance passed against the exact ZIP SHA recorded below.

## Apple Silicon: CI build, signature and relocated app

**380 Python/Qt tests passed** and native PCM tests passed. The arm64 app was ad-hoc signed, 197 Mach-O files were audited, and the complete ZIP was extracted into a different directory. Independent FFmpeg acquisition, startup, GUI lifecycle, CPU inference and three-format output passed. Whisper Base's Metal path passed.

**Qwen3-ASR Metal is not verified:** the CI Apple Paravirtual GPU lacks the required Apple7 matrix capability. That case is explicitly skipped, not counted as a GPU success. Native Anime Whisper inference and the complete 20-model matrix were verified on Windows, not on a physical Mac. The Mac package is not notarized.
