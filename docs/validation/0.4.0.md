## Windows (RTX 4080, physical machine)

The exact Windows ZIP passed a fresh complete 21-model inference and RPP/OTIO/JSON export matrix with separately prepared pinned weights, with 20 Vulkan cases and the CPU-only ReazonSpeech case. The pass was not assembled from separate attempts. On the first run of the same ZIP, Whisper Tiny encountered an access violation in the NVIDIA driver module `nvgpucomp64.dll`; both a same-settings isolated diagnostic and the subsequent complete matrix passed. The intermittent failure was not reproduced or diagnosed to a root cause. The previous candidate exposed a VibeVoice export error when a speaker label was empty. The tested fix uses a non-blank track display name without changing the raw speaker label or edit interval.

30B-A4B passed on a short natural Japanese recording using independent VAD windows and Qwen Forced Aligner, without a fallback to 30B native CTC or native speaker IDs. These are functional tests, not claims of Japanese accuracy on long recordings or better recognition from readings. The 30B model weights are a separate download.


Additional Windows tests on the same ZIP: the isolated frozen GUI successfully ran its default Anime Whisper inference. The 30B no-hint run retained all 92 aligned units. In a separate 30B run with a deliberately irrelevant synthetic Japanese reading and an independent diarizer, two speakers were labeled and some units remained unknown or overlapping. The hint also induced invented text. The aligner produced four rows outside one short crop for that invented text; those rows were omitted from the edit output with warnings, while the raw data was retained. This test verifies wiring, not glossary accuracy or alignment completeness. Raw JSON settings and diagnostics can contain a glossary entry and its reading even if the exact spelling does not appear in the transcript, so review such files before sharing.

## macOS (Apple Silicon CI)

The exact arm64 package passed signature, relocation, lifecycle and export checks. The build is ad-hoc signed, not notarized. Whisper Base was verified using Metal. Qwen3-ASR on Metal was skipped because the virtual GPU lacked the Apple7 feature needed by that backend. 30B-A4B inference was not verified on physical macOS hardware.
